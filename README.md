# 영어 편의점 (English Store)

초등학생용 **영단어 학습 게임 웹앱**입니다. 단어를 외워 「영머니」를 벌고,
앱 안 편의점에서 상품을 골라 **부모가 실제로 사 주는** 구조입니다.

- 편의점 — https://bominpark-droid.github.io/English-convinience-store/
- 단어 퀘스트 — https://bominpark-droid.github.io/English-convinience-store/quest.html

## 이 저장소를 고치기 전에

**반드시 [CLAUDE.md](CLAUDE.md) 를 먼저 끝까지 읽으세요.**
어렵게 고친 것들에 「되돌리지 말 것」이라고 적어 두었습니다 (소리가 안 나던 버그,
복습이 폭증하던 문제, 마이크가 사라지던 문제 등). 모르고 되돌리면 같은 사고가 반복됩니다.

## 파일

| 파일 | 무엇 |
|---|---|
| `index.html` | **영어 편의점 본체.** 화면·글·코드가 한 파일 (약 3,500줄). 쪼개지 마세요 |
| `quest.html` | **단어 퀘스트** — 블록 캐릭터 단어 RPG. 단어 DB가 `index.html` 의 사본이라 **같이** 고쳐야 합니다 |
| `sw.js` · `manifest.json` · `icon-*.png` | **오프라인 담당.** 인터넷 없이도 앱이 열립니다 |
| `CLAUDE.md` | **규칙서.** 기능별 설계·확정값·되돌리지 말 것 목록 |
| `프로젝트_설정/` | 클로드 프로젝트에 넣을 지침·안내 |

서버(`Code.gs`, 구글 앱스 스크립트)는 비밀번호 암호화 규칙이 들어 있어 **이 공개 저장소에 두지 않습니다.**

## 고친 뒤 꼭 할 것

1. 문법 검사 — `script` 안의 내용을 뽑아 검사하고, `onclick=` 으로 부르는 함수가 전부 정의돼 있는지 확인
2. 브라우저로 실제 화면을 열어 눌러 보기
3. 올린 뒤 배포가 끝날 때까지 기다리고, 실제 주소를 받아 새 코드가 들어갔는지 확인
4. 올리기 전 index.html 의 `APP_VER` 를 올립니다. 아이 기기는 앱을 **완전히 닫았다 다시 열면** 새 판이 보이고,
   켜 둔 채라도 다시 볼 때 새 판으로 바뀌거나 「🆕 새 버전이 나왔어!」 띠가 뜹니다. 설정 맨 아래 「앱 버전」으로 확인
