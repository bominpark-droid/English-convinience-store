# 프로젝트 만드는 법 — 깃허브 연결 방식 (대표님용)

한 번만 해 두면, 그 프로젝트 안의 **모든 대화가 저절로 맥락을 갖고
언제나 「지금 코드」를 읽습니다.** 매번 긴 설명을 붙여넣을 필요가 없어집니다.

## 왜 깃허브를 연결하나

| | 파일을 올려 두면 | 깃허브를 연결하면 |
|---|---|---|
| 코드가 바뀌었을 때 | 올려둔 사본은 **그대로 낡는다** | **저절로 최신** |
| 위험 | 낡은 코드를 보고 고쳐 멀쩡한 기능을 망가뜨림 | 없음 |
| 손이 가는 일 | 바뀔 때마다 다시 올려야 함 | 없음 |

그래서 **코드 파일은 올리지 않고 깃허브를 연결**합니다.

---

## 1. 프로젝트를 만든다

클로드 앱 왼쪽 **[프로젝트]** → **[새 프로젝트]**
이름: `영어 편의점`

## 2. 깃허브를 연결한다

프로젝트 화면에서 **[파일 추가]** 또는 **[지식 추가]** → **[GitHub]** 을 고른다.
(처음이면 깃허브 로그인 한 번 → 저장소 접근 허용)

연결할 저장소: **`bominpark-droid/English-convinience-store`**

> 깃허브 화면이 영어로 뜨면 — 초록색 **Authorize** 또는 **Install** 단추를 누르면 됩니다.
> 저장소를 고르라고 하면 `English-convinience-store` 하나만 골라도 충분합니다.

## 3. 프로젝트 지침을 넣는다

프로젝트 화면 오른쪽 **[지침 설정]** 을 누르고,
같은 폴더의 **`1_프로젝트지침.txt`** 내용을 통째로 복사해 붙여넣는다.

## 4. 요약 파일 하나만 더 올린다 (선택)

**`2_앱_한눈에.md`** — 기능·함정·이력을 한 장으로 요약한 것.
깃허브만으로도 되지만, 이게 있으면 클로드가 더 빨리 전체 그림을 잡는다.

## 5. 올리지 않는 것

- **`Code.gs`** (서버 코드) — 비밀번호 암호화 규칙이 들어 있다. 이 맥 폴더에만 둔다.
- 코드 파일을 **복사해서 붙여넣지 않는다** — 깃허브 연결이 그 일을 대신한다.

---

## 다 됐는지 확인하는 법

그 프로젝트 안에서 새 대화를 열고 이렇게 물어본다.

> 영어 편의점 index.html 에서 인형뽑기 경품 최저 가격이 얼마로 돼 있어?

**「700원」** 이라고 답하면 깃허브가 제대로 연결된 것이다.
(숫자를 못 찾거나 딴소리를 하면 2번을 다시 확인한다.)

## 앞으로 쓰는 법 — 두 자리를 나눠 쓴다

| 할 일 | 어디서 |
|---|---|
| **의논·계획·질문** — "이 기능 어떻게 만들까?", "왜 이렇게 돼 있어?" | **프로젝트 대화** (폰에서도 됨) |
| **실제로 고치고 올리기** | **클로드코드** (이 맥) |

프로젝트 대화에서 "이렇게 고치자"까지 정하고,
클로드코드 창에 **"프로젝트에서 정한 대로 고쳐줘"** 라고 하면 이어집니다.

### 자주 쓰는 말

- "아들 새 시험지 단어 넣어줘" (+ 시험지 사진)
- "오락실에 게임 하나 더 추가해줘"
- "발음이 안 나온대, 확인해줘"
- "지금 어디까지 돼 있어?"

---

## 가끔 해 주면 좋은 것

기능이 많이 바뀌면 클로드코드에게 **"앱 한눈에 파일 갱신해줘"** 라고 하면
`2_앱_한눈에.md` 를 새로 만들어 줍니다. 그걸 프로젝트에 다시 올리면 됩니다.
(깃허브로 읽는 코드는 저절로 최신이라 따로 할 일이 없습니다.)
