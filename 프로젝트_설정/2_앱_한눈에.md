> 프로젝트 지식 파일 — 전체 그림 요약. **코드 본문은 일부러 안 넣었다.**

## 무엇인가

초등학생용 영단어 학습 게임 웹앱. 단어를 외워 **「영머니」** 를 벌고,
앱 안 편의점에서 상품을 골라 **부모가 실제로 사 주는** 구조다.
돈 감각까지 같이 배우게 하려고 상품 가격을 실제 편의점 가격으로 넣었다.

## 파일 넷

| 파일 | 무엇 | 주의 |
|---|---|---|
| `index.html` | **영어 편의점 본체.** 화면·글·코드가 한 파일 (약 3,500줄) | 파일을 쪼개지 말 것 |
| `quest.html` | **단어 퀘스트.** 로블록스풍 블록 히어로 RPG, 별도 페이지 | 단어 DB가 index.html 의 사본 — 단어 고치면 **두 파일 같이** |
| `sw.js` · `manifest.json` · `icon-*.png` | **오프라인 담당.** 인터넷 없이도 앱이 열리게 | 브라우저가 별도 파일을 요구해 어쩔 수 없이 분리 |
| `Code.gs` | **서버.** 구글 앱스 스크립트 + 구글시트(사용자·상태·이벤트·상점·퀘스트) | **공개 저장소에 올리지 말 것** · 고치면 대표가 재배포 |

외부 의존성은 구글 글꼴(Jua) 하나뿐. 빌드 과정도 없고 리액트 같은 것도 안 쓴다.

## 지금 들어 있는 기능

### 매일 학습
- **4단계**: 단어 카드 → 예문 빈칸 → 말하기(1번만 해도 넘어감) → 퀴즈
- **왕초보(레벨 0)는 말하기 단계가 없다** — 7살에게 부담이 컸다
- **복습(라이트너 방식)**: 1·3·7·14·30·60일 뒤 재출제. 6번 맞히면 🎓 졸업(다시 안 나옴),
  틀리면 한 칸만 내려감. **하루 상한 20개** (한때 400개까지 밀렸다)
- **레벨 0~5**, 각 75단어. 레벨 0은 7세용 한국 초등 1학년 필수 단어

### 레벨과 보상
- 그 레벨 단어 75개를 다 외우면 레벨업 → **500원 + 랜덤 선물(700~5,000원)**
- 홈 화면에 「다음 레벨까지 N개 남았어」 진행 막대

### 편의점
- 상품 구매 → 영수증에 쌓임 → 부모가 사 준 뒤 「받았어요」 표시
- **무르기(환불)** — 잘못 산 것은 영머니를 정확히 돌려받음 (뽑기·선물은 불가)
- **인형뽑기** 1회 1,000원, 경품은 **700~3,000원** 상품 (장난 상품이 나오던 것 막음)
- **영어 오락실** — 두더지 잡기 · 풍선 터뜨리기.
  1판 100원·60초, 맞히면 10원, **게임마다 하루 5판 · 하루 300원까지**

### 학교 스펠링 (아들 학교 시험 대비)
부모가 학교 시험 단어를 넣으면 아이가 연습한다. 지금 세트 셋.
- **단어 보기 → 🔗 짝 맞추기 → ✍️ 스펠링 연습 → 📝 테스트**
- **짝 맞추기가 핵심** — 실제 시험이 「뜻 ↔ 단어 선 긋기」라 같은 형태로 연습한다
- 문제는 **영어 뜻풀이**, 답은 **단어 스펠링**. 소리 힌트는 없다(들려주면 받아쓰기가 된다)

### 그 밖에
- 주말 보스 퀴즈(토·일) · 오답 집중 훈련
- **부모 모드**(잠금번호 4자리) — 상점·레벨·복습상한·학교단어 관리가 여기 숨어 있다
- **가족별 상점** — 계정마다 상점이 따로. 지인 가족도 같은 주소로 가입만 하면 됨
- **오프라인 작동** — 비행기 모드에서도 열리고, 연결되면 자동으로 서버에 올림

## 꼭 알아야 할 함정 다섯

1. **새로고침 두 번** — 고쳐도 한 번만으로는 안 보인다. 대표에게 안내할 때 꼭 넣을 것
2. **Code.gs 는 재배포해야 반영** — 앱스 스크립트에서 「새 버전으로 배포」. 저장만으론 안 됨
3. **다른 채팅방과 겹침** — 작업 전 `git fetch` + `git log HEAD..origin/main` 필수
4. **문법 검증 필수** — 과거 이걸 빠뜨려 화면이 통째로 죽은 적 있다
5. **CLAUDE.md 의 「되돌리지 말 것」** — 소리 안 나는 버그, 복습 폭증, 마이크 사라짐 등
   어렵게 고친 것들이 적혀 있다. 모르고 되돌리면 같은 사고가 난다
